# SmartCharge Urban — EV Charging Station Analytics

Team project for **Industry 4.0** course as part of the IIT Madras BS in Data Science and Applications.

**Team:** Strategic Signal  
**Members:** Samyuktha, Pulkit, Himanshu, Tarika, Subash

## Overview

Analysed **1,320 EV charging sessions across 462 stations in five US cities** to investigate charging patterns, benchmark station efficiency and explore data-driven infrastructure expansion strategies.

## Methodology

- **Exploratory Data Analysis:** Charging patterns, temporal demand and user–charger segmentation.
- **Efficiency Benchmarking:** Output-oriented BCC Data Envelopment Analysis (DEA).
- **Regression & Machine Learning:** Station-level session modelling and comparison of regression and ensemble models.
- **Capacity Optimisation:** Integer linear programming to allocate charging units under a \$500,000 budget.
- **Station Ranking:** Composite scoring using efficiency, utilisation, session volume and cost.
